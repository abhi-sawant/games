# Games

Offline puzzle, board and card games: a PWA that also ships as an Android app through Capacitor. A home page links to each game.

- **Sudoku**: 20,000 bundled puzzles (5,000 each for Easy, Medium, Hard, Expert) from the public-domain
  [Sudoku Exchange Puzzle Bank](https://github.com/grantm/sudoku-exchange-puzzle-bank).
  Notes, undo, hints, mistake highlighting, a pausable timer, best times per level, and auto-saved progress.
- **Minesweeper**: Beginner, Intermediate and Expert boards with a safe first click, flags (long-press, right-click
  or flag mode), chording, a pausable timer, history and stats per level, and auto-saved progress.
- **2248**: drag a path through matching numbers (or each one step higher) to merge them; the sum rounds up to
  the next power of two. Ported from [Parth2500/2248-Merge](https://github.com/Parth2500/2248-Merge), with score,
  game over detection, history and stats per game, and auto-saved progress.
- **2048**: swipe or use the arrow keys to slide the tiles; equal tiles merge. One-step undo, a "keep going"
  option after 2048, score, history and stats, and auto-saved progress.
- **Tic-tac-toe**: play the computer (Easy, Medium, or a Hard opponent that never loses) or a friend on one
  screen. Rounds alternate who goes first, with a running tally, undo, history and win/draw/loss stats per level.
- **Dots and Boxes**: a 4×4-box board against the computer (Easy, Medium, or a Hard opponent that plans the
  endgame and uses the double-cross) or a friend on one screen. Closing a box claims it and you go again.
  Undo, alternating first move, history and win/draw/loss stats per level.
- **Killer Sudoku** and **Kakuro**: sum puzzles with notes, mistake highlighting and a pausable timer.
- **Calcudoku, Futoshiki, Skyscrapers, Jigsaw Sudoku, Sudoku X**: Latin-square puzzles on one shared board
  (`src/shared/latin-board.ts`), with one solver for cages, inequality signs, edge clues, regions and diagonals
  (`src/shared/latin.ts`). Their generators share `scripts/latin-gen.ts`.
- **Nonograms, Takuzu, Nurikabe, Hitori, Star Battle**: bundled grid-logic puzzles, each with exactly one solution,
  generated by `npm run gen-puzzles` (`scripts/gen-<game>.ts`, run with Node 24's type stripping).
- **Tents, Light Up, Heyawake, LITS, Slitherlink, Masyu, Bridges, Flow**: more logic puzzles on one shared page
  (`src/shared/logic-board.ts`): a puzzle is one number per slot (a cell, a loop edge, a bridge), with undo, hints
  and a check against the rules. Each has its own solver in `src/<game>/solver.ts`; Slitherlink and Masyu share one
  that colours the inside of the loop (`src/shared/loopsolver.ts`), and the line-drawn boards share an SVG lattice
  (`src/shared/lattice.ts`). Every puzzle has exactly one solution except Flow's, which accepts any filling.
- **Lights Out**: every tap flips a light and its neighbours; boards are made by random taps so they're always solvable,
  and Hint shows a move from the shortest solution.
- **Threes** and **15-puzzle**: slide-and-merge and sliding-tile puzzles with undo, history and stats.
- **Sokoban, Rush Hour, Peg Solitaire**: on the shared logic page. Sokoban levels are made backwards, by pulling
  boxes off their targets, so all can be solved; Rush Hour starts each board at the position furthest from a way
  out. Both are graded by their fewest moves, and hints come from a search from wherever you are. Peg Solitaire
  plays the English, European and triangle boards.
- **Connect Four, Reversi, Gomoku, Nine Men's Morris, Checkers**: against the computer (Easy, Medium, Hard, searched in a
  Web Worker) or a friend on one screen, with tally, undo, history and stats.
- **Mancala, Ultimate Tic-tac-toe, Hex, Go, Chess, Backgammon**: the same match runner. Hex and Go choose moves by
  Monte Carlo tree search (`src/shared/mcts.ts`); chess has its own engine (`src/chess/engine.ts`, checked by perft);
  backgammon rolls from a seed kept with each round, so a replay rolls the same dice and Undo can't reroll.
- **Battleship**: against the computer only, since one screen can't hide two fleets. Easy fires at random, Medium
  follows up hits, Hard fires where the remaining ships most often fit.
- **Klondike** (draw 1 or 3) and **FreeCell** (numbered Microsoft-compatible deals): drag or tap to move, undo, timer,
  history and stats.
- **Spider** (1, 2 or 4 suits), **Yukon**, **Canfield**, **Forty Thieves**, **Pyramid**, **TriPeaks** and **Golf**: the
  same table and controls, run by a shared solitaire loop (`src/cards/solitaire.ts`) that ends a deal when no move is left.
- **Word Guess, Word Search, Letter Wheel**: word games in berry. Word Guess has a daily word, the same for everyone,
  and unlimited play; Word Search makes a fresh themed grid each game; Letter Wheel fills a little crossword from a
  wheel of letters. Their words come from `scripts/words/common.txt` (written for these games) and the system word
  list, `/usr/share/dict/words` (Webster's Second International, public domain), via `scripts/gen-words.ts`.
- **Yacht, Farkle, Pig**: dice games in plum, sharing a dice row (`src/dice/`). Yacht is played alone for a high score
  or against the computer, which plans its holds by playing rerolls out; Farkle and Pig are races against the
  computer or a friend. Rolls are saved with the game, so a reload never rerolls.
- Works with no connection: the service worker installs with just the home page, caches each game when it's opened,
  then fetches the rest in the background, the open game first (see `src/sw.ts`).

## Layout

Each game is its own page with its own folder of code; the root page is the game picker.

```
index.html, src/main.ts, src/style.css   home page
src/sw.ts, src/pwa.ts                    the service worker, and the registration every page imports
src/base.css                             the shared Riso design: inks, type, buttons, top bar, tools, dialogs
src/fonts/                               Recursive, self-hosted so the app works offline
sudoku/index.html, src/sudoku/           Sudoku
minesweeper/index.html, src/minesweeper/ Minesweeper
2248/index.html, src/2248/               2248
2048/index.html, src/2048/               2048
tictactoe/index.html, src/tictactoe/     Tic-tac-toe
dots/index.html, src/dots/               Dots and Boxes
<game>/index.html, src/<game>/           the newer games: killer, kakuro, calcudoku, futoshiki, skyscrapers, jigsaw,
                                         sudokux, nonograms, takuzu, nurikabe, hitori, starbattle, lightsout, tents,
                                         lightup, heyawake, lits, slitherlink, masyu, bridges, flow, threes, fifteen,
                                         sokoban, rushhour, pegs, connect4, reversi, gomoku, morris, checkers,
                                         mancala, ultimate, hex, go, chess, backgammon, battleship, klondike,
                                         freecell, spider, yukon, canfield, fortythieves, pyramid, tripeaks, golf,
                                         wordguess, wordsearch, letterwheel, yacht, farkle, pig
src/dice/                                dice drawing and rolling, and the race layout, for the dice games
src/shared/                              helpers the newer games share: screens, timer, storage, puzzle loading,
                                         grid.css for the grid puzzles, the match runner, search and styles for
                                         the two-sided board games (vsmatch.ts, vs.ts, vs.css, mcts.ts), the
                                         Latin-square board and solver (latin*.ts), and the logic page with its
                                         lattice and loop solver (logic-board.ts, logic.css, lattice.ts,
                                         loopsolver.ts)
src/cards/                               deck (one or two decks), card drawing and drag, and the solitaire loop
scripts/gen-<game>.ts                    puzzle generators writing public/puzzles/<game>/<level>.txt; the slow
                                         ones spread over every core with scripts/parallel-gen.ts
src/tiles.css                            the number-tile colour scale shared by 2248 and 2048
```

Every page follows the Riso design language in [DESIGN.md](DESIGN.md): every game belongs to a category (a home page
section), prints in that category's ink, and reuses the shared components in `src/base.css`. To add a game, follow "Adding a new game" in DESIGN.md (pick its category, or add one, a
stylesheet that imports `base.css`, the page, and a home card), then add its folder name to `games`
in `vite.config.ts`, in home page order; the service worker learns its files from the build. Link to pages as `/<game>/index.html`, not `/<game>/`: the Android
app's local server answers extensionless paths with the root page. Keep saved data under a `<game>.` localStorage prefix.

## Web (PWA)

```bash
npm install
npm run dev       # development server
npm run build     # production build in dist/
npm run preview   # serve dist/ (the service worker only runs in a build)
```

Deploy `dist/` to any static host served over HTTPS.

## Android

Requires the Android SDK. Gradle 9.5 is pinned in `android/gradle/wrapper` so the build runs on Java 25
(the JDK bundled with current Android Studio).

```bash
npm run android:sync   # build the web app and copy it into android/
npm run android:open   # open in Android Studio to run or make a signed release
npm run android:apk    # or build a debug APK: android/app/build/outputs/apk/debug/app-debug.apk
```

Set `JAVA_HOME` if Gradle can't find a JDK, e.g.
`export JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home"`.

## Releasing

The version lives only in `package.json`; the Android build derives `versionName` and `versionCode`
(`X*10000 + Y*100 + Z`) from it. Release builds are signed from `android/keystore.properties` (gitignored):

```properties
storeFile=keystore/games.jks
storePassword=...
keyAlias=games
keyPassword=...
```

In Claude Code, `/release X.Y.Z` bumps the version, updates `CHANGELOG.md`, builds, and assembles
`releases/vX.Y.Z/` with the signed APK, the PWA zip for `https://games.slowatcoding.com`, checksums and release notes.

## Puzzles

`public/puzzles/<level>.txt` holds one puzzle per line (81 digits, `0` = empty). To regenerate them,
download the four bank files and run:

```bash
node scripts/pack-puzzles.mjs path/to/bank
```

Expert uses the bank's "diabolical" puzzles with ratings up to 7.0. Harder ones need forcing chains.

## Icons

`public/icon.svg` is the source. Regenerate with `npx pwa-assets-generator --preset minimal-2023 public/icon.svg`
(web) and `npx capacitor-assets generate --android` (Android, from `assets/icon-only.png`).
